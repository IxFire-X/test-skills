> Формат вдохновлён [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-07-07

> Первый релиз скилла.

### Добавлено
- **Контракт входа:** `<raw_content>` (обязателен), `<content_type>` (опционально, по умолчанию `auto`), `<file_path>` (опционально, для batch-режима).
- **Прямой режим:** `analytics` / `source_code` / `test_cases` / `requirements` / `concept` — оборачивание содержимого в явно указанный XML-тег.
- **Автоопределение типа (`auto`):** алгоритм по ключевым словам (Acceptance Criteria, User Story, аннотации кода, маркеры тест-кейсов) с fallback на `analytics`.
- **Batch-режим:** сканирование директории, автоопределение типа для каждого `.md`-файла, сводка `<batch_marking_result>`.
- Интеграция в `PIPELINE.md` и `.skillsrc` (`skills_registry`) как опциональный препроцессор пайплайна `test-pipeline`.
- `README.md`, `examples.md` — полный комплект документации скилла.

### Исправлено (по итогам аудита)
- **Рассинхрон контракта `<content_type>`:** ранее `SKILL.md` указывал тег как **обязательный**, при этом `.skillsrc` и `USER-GUIDE.md` описывали его как опциональный (с автоопределением). Приведено к единому виду: `<content_type>` — **опционален**, по умолчанию `auto`.

## Как использовать этот CHANGELOG

**Правила ведения:**
1. Новая версия — новая секция сверху.
2. Категории изменений: `Добавлено` / `Изменено` / `Устарело` / `Удалено` / `Исправлено` / `Безопасность`.
3. Версия в `CHANGELOG.md` должна совпадать с `version` в frontmatter `SKILL.md`.
4. Дата — ISO 8601 (`YYYY-MM-DD`).
