# tc-reviewer — Валидатор тест-кейсов

## Что это

AI-скилл, который проверяет качество сгенерированных тест-кейсов. Анализирует структуру, детерминированность, техническую точность, покрытие требований и трассировку к аналитике. Может автоматически исправлять мелкие дефекты.

## Зачем нужен

Сгенерированные тест-кейсы не всегда идеальны с первого раза. Скилл выступает в роли ревьюера: находит пропущенные требования, дубликаты, абстрактные формулировки, технические неточности. Если проблемы мелкие — исправляет сам, если серьёзные — возвращает на доработку.

## Как работает

Получает на вход тест-кейсы (от `tc-generator` или пользователя) и опционально — аналитику и код для кросс-проверки. Проверяет по 30+ критериям:

- **Структура** — есть ли заголовки, нумерация, все обязательные блоки
- **Детерминированность** — нет ли «ИЛИ» в ожидаемых результатах, все ли результаты конкретны
- **Техническая точность** — совпадают ли имена таблиц, коды ошибок, метрики с реальным кодом
- **Покрытие** — все ли требования из аналитики покрыты тестами
- **Лимиты** — не превышены ли ограничения на длину полей

## Что выдаёт

- **Вердикт** — принято, автоматически исправлено или требует доработки
- **Отчёт** — список найденных проблем с пояснениями
- **Исправленные тест-кейсы** — если все проблемы были автоматическими (перенумерация, замена абстрактных фраз на точные имена из кода, форматирование)

## Что НЕ делает

- Не придумывает новые тест-сценарии (это делает `tc-generator`)
- Не меняет бизнес-смысл тестов
- Не генерирует тесты из воздуха

## Место в пайплайне

Второй этап. Получает тест-кейсы от `tc-generator`, передаёт исправленные (или подтверждённые) в `tc-to-autotest`.
