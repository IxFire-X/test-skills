### 4. Добавить `enum` для вердиктов в JSON Schema

**Файлы:**
- `schemas/tc-reviewer-output.schema.json`
- `schemas/autotest-reviewer-output.schema.json`

**Что сделать:**
- Найти поле `verdict` (сейчас тип: `string`).
- Заменить на `enum: ["ПРИНЯТО", "AUTO_FIX_APPLIED", "ТРЕБУЕТ ДОРАБОТКИ"]`.

**Почему важно:** Без `enum` валидатор пропустит опечатку (например, `ПРИНЯТОО`). JSON Schema должна валидировать не только тип, но и допустимые значения (DeepSeek/Qwen: «чёткая структура инструментов с JSON Schema»).
