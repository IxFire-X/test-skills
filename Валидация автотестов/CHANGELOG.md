## [1.2.0] — 2026-07-03

> Унификация контрактов с `CONTRACTS.md` v1.0 по итогам аудита (`audit-report.md`).

### Изменено
- Версия SKILL.md: `1.1` → `1.2`. Структура контракта выхода (`<autotest_review>` + `<review_verdict>` + опц. `<review_comments>` + опц. `<corrected_autotest_code>`) уже соответствовала канону `CONTRACTS.md` §2.
- Чеклист качества дополнен пунктами: корневой блок `<autotest_review>`, `<review_verdict>` из канона `CONTRACTS.md` §3.2.

### Добавлено
- Ссылка на `CONTRACTS.md` в шапке файла.
- Явное указание «корневой блок `<autotest_review>`, не плоский `<review>`» в секции «Структура вывода».
- Пример 2 (Частичное исправление) с `verification_status` — для удобства сопоставления с `doc-fix`.

### Устарело
- Использование плоского `<review>` вместо `<autotest_review>` (ранее фигурировало в Оркестраторе) — заменено на канонический корневой блок.

## [1.1.0] — 2026-07-02

### Добавлено
- Вердикт `AUTO_FIX_APPLIED` (только для предупреждений: добавление `.as("...")`, объединение в `SoftAssertions`, замена `@Test` на `@ParameterizedTest`).
- Возможность автофикса для предупреждений (без правки критических ошибок).

## [1.0.0] — 2026-07-01

### Добавлено
- Базовая валидация Java-автотестов: traceability, анти-паттерны, TODO-корректность, WireMock-покрытие, проверка стека
- Границы ответственности (LLM vs компилятор)
- Severity-градация (КРИТИЧЕСКИ / ПРЕДУПРЕЖДЕНИЕ)
- Вердикты `ПРИНЯТО` / `ТРЕБУЕТ ДОРАБОТКИ`
