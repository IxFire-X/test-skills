> Формат вдохновлён [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3] — 2026-07-03

> Унификация стиля SKILL.md, confidence score, поддержка `trace-mapper.md`.

### Добавлено
- **Секция «СВЯЗЬ С PIPELINE»:** унифицированный блок со ссылкой на `CONTRACTS.md` (канон тегов). Все SKILL.md приведены к единому стилю (аудит, рекомендация #10).
- **Confidence Score:** поле `CONFIDENCE: 0.0–1.0` в `<autotest_review>` — агрегированная уверенность в вердикте (<0.7 = высокая неопределённость).
- **Атрибут `version`:** все корневые выходные блоки (`<autotest_review version="1.3">`, `<review_verdict version="1.3">`, `<corrected_autotest_code version="1.3">`) содержат версию для runtime-проверки совместимости.
- **Связь с `trace-mapper.md`:** ссылка на `shared/trace-mapper.md` — единый формат `<trace_map>` для кросс-валидации traceability.

## [1.2] — 2026-07-03

> Унификация с `CONTRACTS.md` v1.0.

### Изменено
- **Приведение к канону:** корневой блок `<autotest_review>` уже соответствует `CONTRACTS.md` §2 (п.9). Все упоминания плоского `<review>` заменены на `<autotest_review>`.
- **Статус-маркеры:** зафиксированы `ПРИНЯТО`, `AUTO_FIX_APPLIED`, `ТРЕБУЕТ ДОРАБОТКИ` (канон `CONTRACTS.md` §3.2).
- **Ссылка на канон:** добавлена ссылка на `CONTRACTS.md` как единственный источник истины.

## [1.1] — 2026-07-02

> Автофикс для предупреждений, JSON Schema (v3.0+).

### Добавлено
- **Автофикс предупреждений:** autotest-reviewer теперь может применять автофикс для безопасных предупреждений (добавление `.as(...)`, объединение в `SoftAssertions`, замена `@Test` на `@ParameterizedTest`). Критические ошибки по-прежнему требуют возврата в `tc-to-autotest`.
- **JSON Schema (v3.0+):** поддержка `<output_format>json</output_format>` — вывод структурированного JSON по схеме `autotest-reviewer-output.schema.json`.

### Изменено
- **Пороги вердиктов:** уточнены правила: `ПРИНЯТО` — 0 критических + ≤2 предупреждений; `AUTO_FIX_APPLIED` — 0 критических + 3+ предупреждений (все исправимы); `ТРЕБУЕТ ДОРАБОТКИ` — 1+ критических ошибок.

## [1.0] — 2026-06-28

> Первая стабильная версия.

### Добавлено
- Валидация автотестов по 5 категориям: Traceability, Анти-паттерны, TODO-корректность, WireMock-покрытие, Соответствие стеку.
- Границы ответственности: что проверяет (LLM-зона) vs что не проверяет (зона компилятора/линтера).
- Три вердикта: `ПРИНЯТО`, `AUTO_FIX_APPLIED`, `ТРЕБУЕТ ДОРАБОТКИ`.
- Чеклист финальной проверки перед выводом.
