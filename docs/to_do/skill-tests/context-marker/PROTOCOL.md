# Context-marker campaign protocol

This pending campaign follows commit 6375a05: five RED controls, five initial GREEN repetitions, one adversarial pressure run, and five final GREEN repetitions. An active FINAL evaluator receives the exact `canonical_prompt` and ordered `required_skill_inputs` manifest in `00-scenario.json`; it reads those canonical instruction files before `artifacts/inputs/raw-content.json`. Manifest paths resolve from the skill-pack repository root, independently of the campaign command cwd. The raw-input allowlist limits task data, not those canonical instructions. The evaluator records actual commands and UTC timing, and writes one schema-bound context-marker-output.json to its reserved output directory. Existing RED, initial GREEN, pressure, and archived evidence are historical and unchanged; their prompts are not evidence for the rewritten canonical prompt. The snapshot below is harness material only and is excluded from application inputs.

Validate every envelope with `tools/validate_artifact.py`, schema `schemas/context-marker-output.schema.json`, and its exact reserved output path: `artifacts/outputs/<phase>/<rep>/context-marker-output.json` (or `artifacts/outputs/03-pressure/pressure/context-marker-output.json` for pressure). The phase/repetition matrix is the exact list in `00-scenario.json`.

## Final command evidence contract v1

`00-scenario.json` sets `protocol_contract_version: 1`. On each future active effective FINAL-GREEN run, append one `commands` entry for every command actually executed, in execution order. Each entry must contain exactly `id`, `argv`, `cwd`, and `exit_code`; `argv` is the literal argument array, never a shell string, and `cwd` is the absolute campaign root. The same ordered entries must be in both `06-run-metadata.json` and that run's `run-protocol.json`.

The sole validator attempt is the final `commands` entry, with `id: "validate-artifact"`, `exit_code: 0`, and exactly four absolute argv values: the executable, `tools/validate_artifact.py`, `schemas/context-marker-output.schema.json`, and that repetition's exact reserved `context-marker-output.json`. Record no synthesized or reconstructed commands. Existing RED, initial GREEN, pressure, and archived protocol bytes without v1 literal command capture are legacy evidence and remain unchanged.
