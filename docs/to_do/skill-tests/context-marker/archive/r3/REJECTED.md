# Rejected final GREEN batch r3

This archive preserves the complete `04-green-final` batch exactly as observed.
It is not scored, not active campaign evidence, and must not be treated as a
hidden rerun.

Protocol and schema validation were clean for all five repetitions. The semantic
exact-locator rubric failed for `rep-03` and `rep-04`, whose requirement
provenance used decorated `locator — quoted text` values rather than exact
locators. The whole batch is therefore abandoned without rerun; `rep-01`,
`rep-02`, and `rep-05` are otherwise passing but are not carried forward.

The two files under `skill-snapshot/` are byte-for-byte copies of the tested
current skill and local contract, not moved evidence. They make the tested
behavior reproducible without changing the active skill.
