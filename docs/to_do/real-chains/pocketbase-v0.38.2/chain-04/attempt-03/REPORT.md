## Что эта реальная цепочка уже обнаружила и исправила

- `context-marker` терял подтверждённые HTTP/response observables и делал ожидаемый результат недетерминированным;
- `tc-to-autotest` мог скопировать fixture JWT вместо проектно-нативной runtime-аутентификации;
- `autotest-reviewer` ошибочно требовал Java `@DisplayName` от Go-кода.

Все три дефекта переносимости исправлены по фактическим отказам реального проекта, а не по синтетической догадке.
