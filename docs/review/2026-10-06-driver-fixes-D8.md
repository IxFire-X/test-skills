# Дополнение к плану: D8 «Ревью без изоляции не останавливает прогон»

Добавь в `docs/superpowers/plans/2026-10-06-driver-live-fixes.md` пункт D8 и выполни его после D5, до D4. Правила те же: сначала падающий тест, потом исправление, коммит и пуш.

## Зачем

Сейчас ответ `none` на вопрос `reviewer-isolation` останавливает прогон (`REVIEWER_ISOLATION_UNAVAILABLE`). Изоляцию пакет всё равно не проверяет (A2), поэтому хост, ответивший `fresh`, проходит дальше, а хост, честно ответивший «нет», останавливается. Выгоднее соврать. Кроме того, не во всех CLI есть субагенты.

## Что сделать

1. Ответ `none` больше не даёт `REVIEWER_ISOLATION_UNAVAILABLE`. Драйвер выдаёт предупреждение и продолжает ревью тем же порядком частей и в том же формате.
2. Переформулируй вопрос: «Может ли хост выполнить каждую часть ревью в отдельном вызове без истории генерации — субагентом или новым процессом CLI (`claude -p`, `codex exec` и т. п.)?». В `skills/orchestrate/SKILL.md` опиши вариант с отдельным процессом CLI как полноценный `fresh`.
3. При `none` драйвер предупреждает, если сумма входов частей ревью больше одного окна контекста, и советует отдельные процессы. В step5 входы ревьюеров были 1,8 МБ. Порог возьми из параметра run с разумным значением по умолчанию.
4. В terminal result, сводке драйвера и отчёте добавь ось `review_independence: ISOLATED | SELF`.
5. При `SELF` результат `accepted=false` с `reason_code REVIEW_NOT_INDEPENDENT`. Кейсы всё равно публикуются, а в `local-pilot-v1` автотесты генерируются, проходят статическое ревью и запускаются: verification отражает фактический запуск.
6. Флаг run `--accept-self-review` разрешает `accepted=true` при `SELF`. Пометка `review_independence: SELF` при этом остаётся в результате и проекциях.
7. Обнови контракт, схемы terminal result и сводки, `CONTRACTS.md` и release manifest.
8. Тесты на оба режима: `fresh` без изменений поведения; `none` проходит весь маршрут без остановки, даёт `SELF` и `accepted=false`; `none` с `--accept-self-review` даёт `accepted=true`; предупреждение о размере контекста появляется.
