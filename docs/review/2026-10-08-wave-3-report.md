перезаписывается — предложение в описании PR; падение доли убитых мутантов — раздел описания PR.

## Отклонения от дизайна

- **История PIT.** Дизайн предполагал `--historyInputLocation`/`--historyOutputLocation`. Ядро закреплённого
  PIT 1.30.0 их не поддерживает (`ErroringHistoryFactory`: нужен отдельный плагин). Поэтому каждый замер
  `suite-update-v1 --mutation` полный, прошлые замеры лежат в `.pilot-runs/suite-strength/<suite_id>/` вне
  набора, а падение доли считается против долей манифеста.
- **`suite-update-v1` — не попытка пилота.** Профиль драйвера со своим журналом шагов; ревью изменённого идёт
  по производственным планировщику и валидатору вне долговечного состояния, без переноса кэша compact-v1 между
  прогонами: ревьюируется документ только из изменённых кейсов (в Petclinic — 1–2 части вместо 11).
- **Карантин в попытке пилота — на уровне файла по упавшим методам**, ровно как в дизайне; повторов для
  нестабильности внутри попытки нет (одно исполнение по контракту) — нестабильность различает прогон набора.

## Найдено и исправлено по ходу

- Ревью методов в `suite-update-v1` не получало исходников продукта (сценарий 2, BLOCKING ревьюера) — теперь
  получает файлы из provenance и классы, на которые ссылаются изменённые методы.
- Ошибка компиляции отправляла в ремонт все методы файла — теперь приписывается методу по номеру строки.
- Метод, который подготовила автоматизация, но не записала из-за правки человека, считался «своим» и мог
  попасть в карантин — теперь своими считаются только записанные методы.
- Квитанция мутаций читалась с лишней обёрткой — доли не попадали в манифест.

## Отложено

- **Правки SUPPORT при ремонте.** Ремонт меняет методы и добавляет хелперы и импорты, но не правит существующий
  общий код; ошибка в общем коде даёт `REPAIR_FAILED` и карантин.
- **Gradle и pytest в живом наборе.** Механика написана для всех адаптеров (явный прогон карантинных у Gradle
  не передаётся — такие методы помечаются «не запускались»), проверено на Maven step5.
- **Перенос кэша compact-v1 между прогонами** — не нужен для экономии (ревью только изменённого дешевле), но не
  сделан.
- **Живой прогон Petclinic по инструкции волны 2** — делает пользователь; находки исправляются по мере
  поступления.
