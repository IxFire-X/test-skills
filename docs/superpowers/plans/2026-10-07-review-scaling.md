## Журнал решений

- 2026-10-07, Р7 против Р14. Требование «вставка или удаление кейса меняет не больше двух блоков» при «ни одна часть не больше бюджета» невыполнимо в общем виде для непрерывных блоков: если блок [a, b] (a = 0,1·cap, b = 0,9·cap) получает между a и b кейс x = 0,95·cap, любое допустимое разбиение даёт три блока [a][x][b], а обратное удаление из них — снова одного. Локальность достижима только малой заполненностью блоков: замер `content_blocks` на случайных документах — при MIN_FILL 0 (границы только по хешу) 1,9 % нарушений, но блоков в 2,95 раза больше минимума (частей — примерно в 9 раз); при MIN_FILL 0,85 (выбрано) — 40 % нарушений, а Petclinic укладывается в 11 частей (Р14 ≤ 12; при 0,75 уже 16 частей). Выбор: стоимость (Р14) и корректность покрытия, а локальность — замер. Последствие локальности — только стоимость инкрементального ревью: области кейсов переносятся по отпечатку кейса и от границ блоков не зависят, заново смотрятся лишь cross-области изменившихся пар блоков. По букве гейта Р7 не пройден; решение — за пользователем (см. отчёт).
