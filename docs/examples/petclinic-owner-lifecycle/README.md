# Настоящие тест-кейсы большого пилота Spring Petclinic

Здесь опубликованы **64 тест-кейса и 290 шагов** для работы с владельцами, питомцами и визитами в ветеринарной клинике. Это сохранённый результат генерации и отдельного ревью от 7 сентября 2026 года, редакция `r2`.

## Открыть тест-кейсы

- [Читать на GitHub — cases.md](cases.md). У каждого кейса есть цель, предусловия, действия, тестовые данные и ожидаемые результаты.
- [Скачать HTML — cases.html](cases.html). Для просмотра таблиц скачайте файл через **Download raw file** и откройте его в браузере.
- [Исходный документ — cases.json](cases.json). Из него сформированы Markdown и HTML; он также содержит связи с требованиями и техническое описание для автоматизации.

Все три файла скопированы из архива без изменения содержимого. Для публикации сокращены только имена файлов.

## Что подтверждено

После улучшения читаемости весь набор был повторно сгенерирован и проверен в отдельном контексте. Проверяющий выбрал редакцию `r2` с результатом `AUTO_FIX_APPLIED`: в ТК-29 уточнён список шести проверяемых типов питомцев.
