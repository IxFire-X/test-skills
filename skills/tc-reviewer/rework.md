# Ревью доработки (`tc-reviewer:rework-1`)

`status` назвал эту стадию: первое ревью отклонило часть кейсов, генератор исправил их один раз. Второй круг — только по ним; принятые в первом круге ты не видишь и не меняешь.

## Вход
Вид `<sha>.rework-review-view.json` (строит код, не меняй): `candidate` — ссылка для отчёта; `cases` — доработанные кейсы; `first_round` — блокирующие замечания первого круга по каждому; `requirements`, `capabilities` — опора кейсов. Проверь: названное замечанием исправлено, кейс проверяет свои требования, нового дефекта нет.

## Ответ
Тот же `validation_report`, что в первом круге, но:
- `verdict`: `ПРИНЯТО` (`effective` = `candidate`) или `ТРЕБУЕТ ДОРАБОТКИ` (`effective` = `null`). `AUTO_FIX_APPLIED`, `successor_document`, `successor_edits` — отказ `REWORK_REVIEW_FIX`.
- `candidate` и `reviewed_case_ids` — как в виде.
- Блокирующее замечание называет кейс в `related_ids`: кейс не принят окончательно. Замечание без кейса не принимает ни один; про кейс не из вида — не учитывается.
- Контрольных ошибок нет; `codeword_seen` — как в первом круге.
Ответ — `incoming/tc-reviewer-rework-1.json`; при отказе исправь по `fix`, повтор один (`--transport-attempts 2`). Не запускай сборку, не ставь зависимости, не ходи в сеть.
