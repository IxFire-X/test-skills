# Примеры: Тест-кейсы на проверку → Вердикт + Исправленные ТК

Полный эталон для скилла `tc-reviewer`. Показывает обе ветки: ПРИНЯТО и ТРЕБУЕТ ДОРАБОТКИ.

## Ключевые соответствия (чеклист эталона)

| Правило скилла | Как отражено в примере |
|---|---|
| Аналитика — источник правды | Пропущенные ТК (amount validation) добавлены на основе `<analytics_documentation>`, а не кода |
| Поиск заглушек | «данные сохранились в БД» → точный SQL; «Лог записан успешно» → уровень + маска |
| Детерминированность | «HTTP 201 или 200» → исправлено на «HTTP 201» |
| Абстрактные названия | «Тест API» → переименовано |
| Дублирование | ТК-3 (дубликат ТК-2) — удалён |
| AUTO_FIX | Все критические ошибки исправлены автоматически, результат в `<corrected_test_cases>` |
| Покрытие | Недостающие сценарии (amount обязателен, amount > 0) добавлены |
