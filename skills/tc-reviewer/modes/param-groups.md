# Parameter groups — review of cases

A parameter group (`param_group`) is shown once at its first case: its lines with the IDs of the first case and `<параметр>` where the cases differ, then a table with a row per case ID — its value and expected result; the code already checked that the cases differ only in values. Judge every row as its own case (each case ID is still reviewed, found and corrected on its own) and whether the variants are right for the design parameter.
