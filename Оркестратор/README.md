# Оркестратор (orchestrate)

Скилл для координации цепочек других скиллов с контролем итераций, изоляцией контекста и обработкой ошибок.

## Когда использовать

- Нужно выполнить цепочку скиллов в определённом порядке
- Требуется контроль качества на каждом этапе
- Необходима изоляция контекста между агентами
- Есть потребность в автоматическом retry при ошибках

## Вход

- Целевое действие (например, "создать документацию для FeatureFlag")
- Контекст проекта (опционально)

## Выход

- Финальный результат выполнения цепочки скиллов
- Лог выполнения с статусами

## Статус-маркеры

| Статус | Описание |
|--------|----------|
| `completed` | Все скиллы выполнены успешно |
| `partial` | Часть скиллов выполнена |
| `failed` | Ошибка при выполнении |
| `retry` | Требуется повторная попытка |

## Использование

```
Создай документацию для FeatureFlag и проверь её
Проанализируй концепцию WorkflowHandler и исправь ошибки
```
