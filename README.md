Ветка только для готовых папок пакета и страниц о нём. Кода разработки и его истории здесь нет — они в ветках `v06`, `v07`.

## v0.6 (`f43dae16`)
- `v0.6/cases-only/test-skills` — только тест-кейсы; для первого прогона.
- `v0.6/mode-b/test-skills` — кейсы и автотесты.

Рядом с каждой папкой — `SHA256SUMS.txt`. Папка переносится в проект целиком, без архива: `<проект>\.tools\test-skills`.
Проверка после переноса — из папки пакета: `python -m tools.doctor --root .` (сверяет каждый файл с `release/manifest.json`).
Файл `.gitattributes` (`* -text`) запрещает git менять концы строк, поэтому клон или скачанная копия совпадает с манифестом байт в байт.
