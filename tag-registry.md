## Быстрая справка: статус-маркеры

> Полный реестр и семантика: `CONTRACTS.md` §3.

| Маркер | Источник | Реакция оркестратора |
|--------|----------|---------------------|
| `failed` | любой | Остановить, эскалация |
| `ПРИНЯТО` | tc-reviewer, autotest-reviewer | Продолжить |
| `AUTO_FIX_APPLIED` | tc-reviewer, autotest-reviewer | Использовать corrected |
| `ТРЕБУЕТ ДОРАБОТКИ` | tc-reviewer, autotest-reviewer | Приостановить |

## Правила использования

1. **Полный канон — `CONTRACTS.md`.** Этот файл — только справочное сокращение.
2. **При добавлении нового тега** — сначала зарегистрировать в `CONTRACTS.md`, затем обновить здесь (только краткую справку).
3. **При переименовании тега** — обновить `CONTRACTS.md` (канон), затем все SKILL.md, PIPELINE.md, Instruction.md, и этот файл.
4. **При удалении тега** — пометить `@deprecated` с указанием миграции в `CONTRACTS.md`.
5. **Ссылка из SKILL.md:** `<!-- теги: см. CONTRACTS.md §X.Y -->`
